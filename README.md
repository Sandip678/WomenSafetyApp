# 🛡️ Women Safety App (Android)

An Android application designed to enhance personal safety for women through quick emergency alerts and location sharing.

- Android SDK
- Android Studio
- Google Maps / Location APIs (update if used)

## 🚀 How to Run
1. Clone the repository:
   ```
   git clone https://github.com/Sandip678/WomenSafetyApp.git
   ```
2. Open the project in Android Studio.
3. Let Gradle sync complete.
4. Run on an emulator or connected Android device (min SDK: update this).
